# 試聴と外部プレイヤー (app)

- 対象: `PreviewService` / `launchPlayer` / `CachingAudioSource`
- テストコード: `tests/unit/app/PreviewServiceTest.cpp`
- 根拠: docs/SPEC.md §7

## 何を保証するか

書き出す前のスライス（切り出し＋切り口の処理）と、書き出したファイルの両方を試聴できること。曲全体は、すべてのノーツをその時刻に重ねて鳴らすこと。外部プレイヤーを設定どおりに起動すること。

共通の前提: BPM 120、resolution 240、音声は 1000 Hz・モノラル・3000 フレーム。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| PRV-001 | 書き出す前、切りっぱなし | スライスを試聴する | スライスの区間と同じ長さ・同じ値のステレオの音（元の音声は 1 回だけ読む） |
| PRV-002 | フェード（フェードアウト 2 ms） | スライスを試聴する | 最後のフレームが 0 |
| PRV-003 | 書き出した後 | スライスを試聴する | 書き出したファイル（BMS のフォルダ＋ファイル名）を読む |
| PRV-004 | ノーツが y=0 と y=480（1 秒後） | 曲全体を試聴する（出力 1000 Hz） | 1000 フレーム目から 2 つ目のスライスが鳴る。長さは 1 秒＋2 つ目のスライスの長さ |
| PRV-005 | 変換に失敗している | 試聴する | エラーの文言を返し、音はない |
| PRV-006 | 実行ファイルが空／BMS がまだない | 外部プレイヤーを起動する | それぞれエラーの文言を返し、起動しない |
| PRV-007 | 実行ファイル `/opt/player/play`、作業フォルダが空 | 外部プレイヤーを起動する | テンプレートどおりのプログラムと引数（BMS は絶対パス）。作業フォルダは `/opt/player` |
| PRV-008 | 作業フォルダ `/work` | 外部プレイヤーを起動する | 作業フォルダは `/work` |
| PRV-009 | 同じ音声を 2 回調べる、その後 clear | 調べる | 1 回目だけ実際に調べる。clear の後はもう一度調べる |
