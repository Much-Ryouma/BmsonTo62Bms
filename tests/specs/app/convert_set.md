# 譜面セットの変換 (app)

- 対象: `ConvertService::prepareSet`、`ConvertService::summarize`、`defaultBaseIndex`、`guessDifficulty`
- テストコード: `tests/unit/app/ConvertSetTest.cpp`
- 根拠: docs/SPEC.md §5A

## 何を保証するか

同じ曲の複数の難易度の bmson をまとめて変換し、音声ファイルを共有した BMS を譜面ごとに作ること。基準の譜面にないスライスを、チェックに従って切り出すかエラーにすること。

共通の前提: 音声 `a.wav`・`b.wav` は 1000 Hz、10000 フレーム。bmson はすべて `songs/` にある。

- HARD（レベル 10）: `a.wav` に y=0 鍵盤（x=1）、y=240 鍵盤（x=2、c=true）、y=480 BGM（c=true）。`b.wav` に y=0 鍵盤（x=3）。スライスは最初に鳴る順に a(0〜500)・b(0〜10000)・a(500〜1000)・a(1000〜10000) の 4 つ
- EASY（レベル 3）: `a.wav` だけで、HARD と同じ位置のノーツ。スライスは HARD の a の 3 つと同じ
- NORMAL（レベル 5）: `a.wav` に y=0 鍵盤、y=240 鍵盤（c=false）。y=240 で音声の先頭からやり直すため、2 つ目のスライスは a(0〜10000) になり、HARD にない（切り出し位置をそろえても作れない）
- SHORT（レベル 4）: `a.wav` に y=0 鍵盤、y=480 BGM（c=true）。y=240 がないため、そのままでは 1 つ目のスライスが a(0〜1000) になる

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| SET-001 | HARD（基準）と EASY | 変換を準備する | エラーなし。2 譜面とも音声ファイル名の一覧が同じ。EASY の `#WAV` は ID 01・03・04 だけ（b の ID 02 は書かない） |
| SET-002 | HARD（基準）と NORMAL、追加の切り出しなし | 変換を準備する | NORMAL にエラー「基準の譜面にないスライスが 1 個あります」。例として「小節 000 の a.wav」を挙げる。セット全体がエラー |
| SET-003 | SET-002 と同じで、追加の切り出しあり | 変換を準備する | エラーなし。NORMAL に情報「追加で切り出します」。追加のスライスは全体の 5 番目（基準の 4 つの後ろ）の a(0〜10000) で、NORMAL の基準にないスライスは 5 番目だけ |
| SET-004 | HARD は `songs/`、EASY は `other/` | 変換を準備する | エラー「すべて同じフォルダに」 |
| SET-005 | EASY の初めの BPM だけが 150 | 変換を準備する | EASY に警告「BPM・STOP・小節線・resolution のどれかが違います」。HARD にはない |
| SET-006 | HARD は難易度 4、EASY は指定なし | 変換を準備する | HARD の BMS に `#DIFFICULTY 4`。EASY にはない |
| SET-007 | HARD（基準）と EASY | どの譜面がスライスを使うか調べる | b(0〜10000)（2 番目）は HARD だけ。a(0〜500)（1 番目）は両方 |
| SET-008 | レベル 5・10・10 で、鍵盤のノーツが 3・4・6 個 | 初めの基準を決める | 3 番目（レベルが最も高く、同じなら鍵盤のノーツが多い） |

| SET-010 | HARD／読めない bmson | 概要を調べる | 鍵盤のノーツ 3 個（BGM は数えない）、レベル 10／エラーの文 |
| SET-011 | HARD（基準）と SHORT、追加の切り出しなし | 変換を準備する | エラーなし。SHORT の y=0 のノーツは HARD に合わせて a(0〜500) を鳴らし、y=240 に a(500〜1000) の BGM のノーツが加わる（ノーツは 3 個）。スライスは HARD の 4 つだけ。SHORT に情報「ほかの譜面の切り出し位置に合わせて、1 個のノーツ…」 |
| SET-012 | SHORT（基準）と EASY | 変換を準備する | 基準の SHORT のほうが EASY の切り方に合わせて短く切られ、BGM のノーツが 1 個加わる。スライスは 3 つで、EASY に基準にないスライスはない |
