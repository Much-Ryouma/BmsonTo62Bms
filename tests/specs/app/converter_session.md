# 変換のセッション (app)

- 対象: `ConverterSession`
- テストコード: `tests/unit/app/ConverterSessionTest.cpp`
- 根拠: docs/SPEC.md §9.1（画面が使う変換の状態）

## 何を保証するか

画面の操作（bmson を開く、設定を変える、書き出す、試聴する）に合わせて、変換の結果と「書き出し済みかどうか」を正しく保つこと。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| SES-001 | | bmson を開く | 変換の結果ができる。書き出し先は bmson の横の `.bme` |
| SES-002 | bmson を開いた | 設定（名前のパターン）を変える | 変換し直され、音声ファイル名が変わる |
| SES-003 | | 書き出す | 音声ファイルと BMS が書かれ、書き出し済みになる |
| SES-004 | 書き出し済み | 設定を変える／書き出し先を変える | 書き出し済みではなくなる（ファイルと設定が合わなくなるため） |
| SES-005 | まだ書き出していない | 書き出したファイルを試聴する | エラー「まだ書き出していません」 |
| SES-006 | 別の bmson を開く | 音声を調べる | 前の bmson で調べた結果を使わず、調べ直す |
| SES-007 | 変換に失敗している | 書き出す | 書き出さず、エラーを返す |
| SES-008 | `songs/` に HARD（レベル 10）と EASY（convert_set.md と同じ） | HARD を基準に 2 つを開く | 選ばれているのは HARD。書き出し先は譜面ごとに `songs/hard.bme`・`songs/easy.bme`。EASY を選ぶと、変換の結果と書き出し先が EASY のものになる |
| SES-009 | SES-008 と同じ | 書き出す | 音声ファイルは 1 回だけ（4 個）書かれ、BMS は 2 つとも書かれる |
| SES-010 | SES-008 と同じで EASY を選んでいる | 難易度を 1 にする | EASY の BMS にだけ `#DIFFICULTY 1` |
| SES-011 | SES-008 と同じ | EASY の書き出し先を別のフォルダにして書き出す | エラー「すべて同じフォルダに書き出してください」。何も書かない |
