# 変換の流れ (app)

- 対象: `ConvertService` / `renderBms`
- テストコード: `tests/unit/app/ConvertServiceTest.cpp`
- 根拠: docs/SPEC.md §4、§5.9、§8

## 何を保証するか

bmson の読み込みから BMS の書き出しまでを順に行い、利用者に知らせることをメッセージ（エラー・警告・情報）にまとめること。エラーがあるときは書き出さないこと。

ファイルや音声は偽物（テスト用の実装）に差し替えて確かめる。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| CNV-001 | 正しい bmson と音声（曲名 `Title`） | 変換を準備する | BMS の文書ができる。音声ファイル名は既定のパターンで `wav/Title_k0001.wav`、`wav/Title_b0001.wav` |
| CNV-002 | bmson を読み込めない | 変換を準備する | エラー「bmson を読み込めません」。文書はない |
| CNV-003 | 音声ファイルが見つからない | 変換を準備する | エラー（ファイル名を含む）。文書はない |
| CNV-004 | mode_hint が popn-9k | 変換を準備する | エラー。音声は 1 つも調べない |
| CNV-005 | 2 つのチャンネルが同じ音声ファイルを使う | 変換を準備する | その音声は 1 回だけ調べる |
| CNV-006 | 正しい変換結果 | Shift_JIS で書き出す | 書き出し先にバイト列が渡る。改行は CRLF、タイトルは Shift_JIS |
| CNV-007 | タイトルに 🎵、または BGA のファイル名に 🎵 | Shift_JIS で書き出す | タイトルなら警告を出して書き出す。ファイル名ならエラーで書き出さない |
| CNV-008 | `C:/songs/a.bmson` | 既定の書き出し先を求める | `C:/songs/a.bme` |
| CNV-009 | chart_name と title_image がある。同じ位置に鍵盤と BGM のノーツがある | 変換を準備する | chart_name と title_image の警告、BGM を書き出さない旨の情報が出る |
| CNV-010 | `songs/a.bmson` | `songs/a.bme`／`out/a.bme` に書き出す | `songs` では警告なし。`out` では書き出したうえで「別のフォルダ」の警告（BGA などのファイル名は bmson のフォルダが基準のため） |
| CNV-011 | フェードアウト 60 ms、OGG の品質 11、名前のパターンの誤り | 変換を準備する | それぞれエラー。bmson も音声も読まない |
