# 音声ファイルの書き出し (app)

- 対象: `ConvertService::exportSounds` / `sampleRequestFor`
- テストコード: `tests/unit/app/SoundExportTest.cpp`
- 根拠: docs/SPEC.md §6

## 何を保証するか

スライスごとに音声ファイルを書き出すこと。元の音声は 1 つにつき 1 回だけ読み、切りっぱなしなら元の音声とサンプル単位で一致させること。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| EXP-001 | 2 つのチャンネルが同じ音声を使う | 書き出す | 音声は 1 回だけ読む。スライスの数だけファイルを書く |
| EXP-002 | WAV で書き出す | 元の音声の読み方を決める | .wav・.flac はそのままの形式、.ogg・.mp3 は 16 bit。OGG で書き出すときはどれも浮動小数点 |
| EXP-003 | 切りっぱなし | 書き出す | 各ファイルのサンプルが、元の音声の区間と同じ |
| EXP-004 | フェード（フェードアウト 2 ms） | 書き出す | 各ファイルの最後のサンプルが 0 |
| EXP-005 | 元の音声を読めない | 書き出す | エラー（ファイル名を含む）。ほかの音声のスライスは書き出す |
| EXP-006 | OGG、品質 7 | 書き出す | OGG の書き出しに品質 7 が渡る |
| EXP-007 | 実際のファイル（16 bit の WAV と 24 bit の WAV） | 変換して書き出し、書き出したファイルを読む | ビット深度が元と同じで、サンプルが元の区間と同じ |
| EXP-008 | 書き出しの途中 | 進み具合を受け取る | 1 ファイルごとに（済んだ数, 全体の数）が届き、最後は（全体, 全体） |
| EXP-009 | サブフォルダ `wav` | 変換して書き出す | 音声ファイルは BMS の横の `wav/` に書かれる。`#WAV` の定義はファイル名だけ（`#WAV01 <ファイル名>`、`wav/` を付けない） |
