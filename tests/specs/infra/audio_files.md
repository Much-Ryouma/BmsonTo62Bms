# 音声ファイルの読み書き (infra/audio)

- 対象: `decodePcm` / `encodeWav` / `encodeOgg`
- テストコード: `tests/unit/infra/AudioFilesTest.cpp`
- 根拠: docs/SPEC.md §6.1

## 何を保証するか

音声を元のサンプル形式のまま読み、同じ形式の WAV に書けること。OGG に書いたファイルが読めること。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| ACD-001 | 16 bit・ステレオ・44100 Hz の WAV | そのままの形式で読む | S16、2 ch、44100 Hz。サンプルの値が元と同じ |
| ACD-002 | S16・S24・S32・U8・F32 の PcmBuffer | WAV に書いて、そのままの形式で読み戻す | 形式・チャンネル数・サンプルレート・バイト列が同じ |
| ACD-003 | F32 の PcmBuffer | WAV に書く | fmt の形式が 3（浮動小数点）、fmt の長さが 18 |
| ACD-004 | 16 bit の WAV | F32 で読む | F32 で、値は 16 bit の値 ÷ 32768 |
| ACD-005 | 44100 Hz・ステレオ・1 秒のサイン波 | OGG に書いて読み戻す | 44100 Hz・2 ch・44100 フレームで、波形がおおむね同じ（誤差 0.05 以内） |
| ACD-006 | 0 フレーム | WAV と OGG に書く | どちらも読み戻せて、0 フレーム |
