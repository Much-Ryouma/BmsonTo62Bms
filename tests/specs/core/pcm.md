# PCM のサンプル (core/audio)

- 対象: `PcmBuffer` / `sampleAt` / `setSample` / `extractFrames` / `toFloat` / `fitsIn24Bits` / `narrowTo24Bits`
- テストコード: `tests/unit/core/PcmTest.cpp`
- 根拠: docs/SPEC.md §6.1（元と同じビット深度で書く）、§6.3（切りっぱなしならサンプル単位で一致）

## 何を保証するか

元の音声のサンプル形式（8 / 16 / 24 / 32 bit 整数、32 bit 浮動小数点）のまま区間を切り出し、必要な部分だけ値を変えられること。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| PCM-001 | 各形式で 1 サンプル | 値を読む | U8 の 0x80 は 0.0、S16 の -32768 は -1.0、S24 の 0x400000 は 0.5、S32 の 0x40000000 は 0.5、F32 の 0.25 は 0.25 |
| PCM-002 | S16・S24 のすべての値 | 読んだ値をそのまま書き戻す | バイト列が変わらない（読み書きで値がずれない） |
| PCM-003 | S16 | 1.5 と -1.5 を書く | 32767 と -32768（範囲の端で止まる） |
| PCM-004 | ステレオ・S24・10 フレーム | 3〜7 フレーム目を切り出す | 4 フレーム。バイト列は元の 3×6〜7×6 バイト目と同じ |
| PCM-005 | 10 フレーム | -5〜100 フレーム目を切り出す | 0〜10 フレーム（範囲外は切り詰める） |
| PCM-006 | S32 の値が 0x12345600 と 0x12345601 | 24 bit に収まるか調べる | 前者だけなら収まる。後者を含むと収まらない |
| PCM-007 | S32 の 0x12345600 | 24 bit にする | S24 の 0x123456 |
