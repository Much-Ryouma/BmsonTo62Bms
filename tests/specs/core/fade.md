# フェード (core/audio)

- 対象: `applyFade` / `fadeSettingsError`
- テストコード: `tests/unit/core/FadeTest.cpp`
- 根拠: docs/SPEC.md §6.3

## 何を保証するか

「切りっぱなし」では音を変えず、「フェード」では切り口だけに直線のフェードをかけること。

共通の前提: サンプルレート 1000 Hz、モノラル、F32、すべて 1.0 の 100 フレーム（1 ms = 1 フレーム）。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| FAD-001 | 切りっぱなし | フェードをかける | すべて 1.0 のまま |
| FAD-002 | フェード、フェードアウト 4 ms | フェードをかける | 最後の 4 フレームが 0.75・0.5・0.25・0.0。それより前は 1.0 |
| FAD-003 | フェード、フェードイン 4 ms をオン、途中から鳴らすスライス | フェードをかける | 最初の 4 フレームが 0.0・0.25・0.5・0.75 |
| FAD-004 | フェードインをオン、ファイルの先頭から鳴らすスライス | フェードをかける | 最初のフレームは 1.0 のまま（フェードインしない） |
| FAD-005 | フェードアウト 50 ms、10 フレームのスライス | フェードをかける | フェードは 5 フレーム（スライスの半分まで）。最初の 5 フレームは 1.0 |
| FAD-006 | フェードアウト 51 ms／-1 ms、フェードイン 60 ms（オン） | 設定を確かめる | どれもエラー。0〜50 ms なら問題なし |
