# 小節の区切り (core/timing)

- 対象: `MeasureLayout`
- テストコード: `tests/unit/core/MeasureLayoutTest.cpp`
- 根拠: docs/SPEC.md §5.5

## 何を保証するか

bmson の `lines` から BMS の小節を決め、任意のパルスを「何小節目の、小節の先頭から何パルス目か」に変換できること。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| MEA-001 | resolution 240、`lines` なし | y=1000 の位置を求める | 1 小節目の 40 パルス目（4/4 = 960 パルスごと） |
| MEA-002 | `lines` = 0, 960, 1680 | y=1700 の位置と 1 小節目の長さを求める | 2 小節目の 20 パルス目。1 小節目の長さは 720 パルス |
| MEA-003 | `lines` = 0, 720 | 1・2 小節目の先頭と y=1700 の位置を求める | 720 と 1680（最後の線より後は 4/4 が続く）。y=1700 は 2 小節目の 20 パルス目 |
| MEA-004 | `lines` = 480（0 がない） | 0 小節目の長さを求める | 480 パルス（0 を補う） |
| MEA-005 | `lines` = 960, -10, 960 | 小節の先頭を求める | 負の値と重複は無視され、0 と 960 が区切りになる |
