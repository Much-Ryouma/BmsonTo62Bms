# BMS の書き出し (core/bms)

- 対象: `writeBms` / `channelForLane`
- テストコード: `tests/unit/core/BmsWriterTest.cpp`
- 根拠: docs/SPEC.md §5.3〜§5.8、§8

## 何を保証するか

bmson とスライスの割り当てから、ヘッダー・定義・小節データを持つ BMS を組み立てること。ID の数で 36進数と 62進数を切り替え、書けない内容はエラーにすること。

共通の前提: beat-7k、BPM 120、resolution 240（4/4 の 1 小節 = 960 パルス）。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| BMW-001 | タイトル・アーティスト・サブアーティスト 2 人・ジャンル・レベル 7、サブタイトルは空 | 書き出す | `#PLAYER 1`・`#GENRE`・`#TITLE`・`#ARTIST`・`#SUBARTIST`（2 行）・`#BPM 120`・`#PLAYLEVEL 7`・`#DEFEXRANK 134`・`#LNTYPE 1` がある。`#SUBTITLE`・`#TOTAL`・`#BASE` はない |
| BMW-002 | | 難易度の指定なし／3 を指定して書き出す | 指定なしでは `#DIFFICULTY` がない。3 では `#DIFFICULTY 3` |
| BMW-003 | beat-7k | レーン 1〜8 のチャンネルを求める | 11・12・13・14・15・18・19・16。ロングノーツは 51・52・53・54・55・58・59・56 |
| BMW-004 | 0 小節目の y=0 に BGM のノーツが 2 つ | 書き出す | `#00001` の行が 2 行になる |
| BMW-005 | レーン 1 の y=0 と y=480 にノーツ | 書き出す | `#00011:0102`（2 分割で足りる） |
| BMW-006 | `lines` = 0, 720, 1680 | 書き出す | `#00002:0.75` がある。1 小節目（4/4）には `02` の行がない |
| BMW-007 | レーン 1 の y=480 に l=960 のロングノーツ | 書き出す | `#00051:0001` と `#00151:0001`。始点と終点が同じ ID |
| BMW-008 | y=960 で BPM 150.5、y=1920 で BPM 150.5、y=2880 で BPM 90 | 書き出す | `#BPM01 150.5`・`#BPM02 90`。08 チャンネルは同じ値に同じ ID を使う |
| BMW-009 | y=0 に 25 パルスの STOP（resolution 240）と、resolution 480 で 5 パルスの STOP | 書き出す | `#STOP01 5`（25 × 48 ÷ 240）と `#STOP01 0.5`（5 × 48 ÷ 480、小数のまま） |
| BMW-010 | BGA の header が id 5「b.png」と id 3「a.png」。y=0 で id 3 を bga、y=960 で id 5 を layer、y=960 で id 3 を poor | 書き出す | `#BMP01 a.png`・`#BMP02 b.png`（最初に使う順）。`#00004:01`・`#00107:02`・`#00106:01` |
| BMW-011 | bga_events が header にない id 9 を使う | 書き出す | エラー。文書は作られない |
| BMW-012 | スライスが 1295 個／1296 個 | 書き出す | 1295 個では `#BASE` がなく、ID は 36進数（最後は `ZZ`）。1296 個では `#BASE 62` があり、最後の ID は `Ku`（1296 = 20×62 + 56。20 は `K`、56 は `u`）。62進数で書き出した旨の警告が出る |
| BMW-013 | スライスが 3844 個 | 書き出す | エラー（上限 3843 個）。文書は作られない |
| BMW-014 | y = 1000 × 960（1000 小節目）にノーツ | 書き出す | エラー（小節番号は 999 まで） |
| BMW-015 | mode_hint が keyboard-24k（未対応） | 書き出す | エラー |
| BMW-016 | レーン 1 の同じ位置にノーツが 2 つ | 書き出す | 警告。行は 1 行で、先のノーツだけを書く |
| BMW-017 | レーン 1 に y=0（l=480）と y=480（l=480）のロングノーツ | 書き出す | エラー（終点と次の始点が同じ位置になり、BMS では表せない） |
| BMW-018 | | 書き出す | `#WAV`・`#BMP`・`#STAGEFILE` などファイル名を書く行は「ファイル名の行」として区別される（文字コードの検査に使う） |
| BMW-019 | beat-14k、レーン 1・9・16 と、レーン 14 のロングノーツ | 書き出す | `#PLAYER 3`。11・21・26 チャンネルと、68 チャンネル（2P の 6 鍵のロングノーツ）の行がある |
| BMW-020 | popn-9k、レーン 5・6・9、judge_rank 100 | 書き出す | `#PLAYER 1`。15・22・25 チャンネルの行がある。`#DEFEXRANK 143`（143 × 70 ÷ 100 = 100） |
| BMW-021 | スライスが 3 つで、ノーツは 1 番目と 3 番目だけを使う（譜面セットのほかの難易度） | 書き出す | `#WAV01` と `#WAV03` だけを書く（使わない ID は定義しない）。使う最大の ID は 3、定義の数は 2 |
| BMW-022 | スライスが 1300 個で、ノーツは 1〜10 番目だけを使う | 書き出す | 36進数のまま（進数は使う最大の ID で決める）。`#BASE` の行はない |
