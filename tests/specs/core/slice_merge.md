# 譜面セットのスライスのまとめ (core/slicing)

- 対象: `alignSliceCuts`、`mergeSlicePlans`、`MergedSlices::planFor`
- テストコード: `tests/unit/core/SliceMergeTest.cpp`
- 根拠: docs/SPEC.md §5A.3、§5A.4

## 何を保証するか

譜面どうしで同じ音の切り出し位置をそろえ（短いほうの切り方に合わせる）、複数の譜面のスライスを 1 つの一覧にまとめ、同じ音には同じ番号（ID）を振ること。基準の譜面にないスライスを譜面ごとに見分けられること。

共通の前提: スライスは「元の音声・開始フレーム・終了フレーム」で表す。サンプルレート 1000 Hz、BPM 120、resolution 240（y=240 は 0.5 秒 = 500 フレーム）。譜面 0・1・2 のうち、特に書かなければ譜面 0 が基準。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| MRG-001 | 譜面 0 に a(0〜100)・a(100〜200)、譜面 1 に a(100〜200) | まとめる | スライスは 2 つ。譜面 1 の a(100〜200) は全体の 2 番目を指す |
| MRG-002 | 基準は譜面 1。譜面 0 に a(0〜100)、譜面 1 に b(0〜100) | まとめる | 全体の 1 番目は b（基準の譜面が先頭）、2 番目は a |
| MRG-003 | 譜面 0 に a(0〜100)、譜面 1 に a(0〜50)、譜面 2 に a(0〜30)・a(0〜50) | まとめる | 並びは a(0〜100)、a(0〜50)、a(0〜30)（譜面の順、その中は最初に鳴る順）。基準にないスライスは、譜面 1 が 2 番目、譜面 2 が 2・3 番目。譜面 0 はなし |
| MRG-004 | 譜面 0 で a(0〜100) を BGM（位置 0）、譜面 1 で同じ区間を鍵盤（位置 480、レーン 3） | まとめる | パラ音になり、最初の位置は 480、レーンは 3 |
| MRG-005 | 譜面 0 に鍵盤 1 つと BGM 1 つ、譜面 1 に追加の鍵盤 1 つ・BGM 1 つ | まとめる | 番号は鍵盤 1・2、BGM 1・2（すべての譜面を通した連番） |
| MRG-006 | 譜面 1 のノーツが、譜面 1 のスライスの 1 番目を指す。そのスライスは全体の 3 番目 | 譜面 1 の計画を作る | スライスは全体の一覧。ノーツは 3 番目を指す。レーン・位置・長さはそのまま |
| MRG-007 | 譜面が 2 つ | 基準を 2 番（範囲外）にしてまとめる | 例外 |
| MRG-008 | 譜面 0 は y=0 の鍵盤（レーン 1）で a(0〜1000)。譜面 1 は y=0 で a(0〜500)、y=240 で a(500〜1000) | 切り出し位置をそろえる | 譜面 0 のノーツは a(0〜500) を鳴らし、y=240 に a(500〜1000) を鳴らす BGM のノーツが加わる（短く切ったノーツ 1 個、加えたノーツ 1 個）。譜面 1 は変わらない |
| MRG-009 | 譜面 0 は MRG-008 と同じ。譜面 1 は y=240 で a(200〜1000)（y=240 の時刻に 500 フレーム目を鳴らさない、別のやり直しの区間） | 切り出し位置をそろえる | 譜面 0 は切らない（同じ時刻に同じ位置を鳴らす切断位置だけを使う） |
| MRG-010 | 譜面 0 は y=0 にレーン 1・2 の和音で a(0〜1000)。譜面 1 は MRG-008 と同じ切り方（BGM） | 切り出し位置をそろえる | 短く切ったノーツは 2 個、加える BGM のノーツは 1 個だけ（続きが二重に鳴らないように） |
| MRG-011 | MRG-008 と同じ | そろえてからまとめる | スライスは 2 つで、譜面 1 に基準にないスライスはない。a(500〜1000) は譜面 1 で鍵盤に置かれるのでパラ音 |
