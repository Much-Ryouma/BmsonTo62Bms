# 名前のパターン (core/naming)

- 対象: `NamePattern`
- テストコード: `tests/unit/core/NamePatternTest.cpp`
- 根拠: docs/SPEC.md §6.2.1、§6.2.2

## 何を保証するか

パターン文字列の `{変数}` と `{変数:書式}` を、printf と同じ考え方で値に置き換えること。書き間違いは、理由の分かるエラーにすること。

共通の値: song = `とても長い曲のタイトル`、src = `drums`、id = `0a`、lane = 3、measure = 12、index = 7。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| NMP-001 | `{song:.4}_k{index:04}` | 置き換える | `とても長_k0007`（4 文字。バイト数ではなく文字数で数える） |
| NMP-002 | `{index:3}`・`{index}`・`{index:02}`（index 123） | 置き換える | `  7`・`7`・`123`（桁数より大きい値は切り詰めない） |
| NMP-003 | `{index:%04d}`・`{song:%.2s}` | 置き換える | `0007`・`とて`（printf の書き方も受け付ける） |
| NMP-004 | `{src}-{lane}-{measure:03}-{id}` | 置き換える | `drums-3-012-0a` |
| NMP-005 | `{{x}}` | 置き換える | `{x}` |
| NMP-006 | `{oops}`・`{index`・`a}b`・`{index:.3}`・`{song:04}`・`{index:x}`・`{index:099}` | 読み込む | どれもエラー |
| NMP-007 | サブフォルダ用で `{song}`・`{index}`・空文字列 | 読み込む | `{song}` と空文字列は使える。`{index}` はエラー |
| NMP-008 | ファイル名用で空文字列 | 読み込む | エラー |
