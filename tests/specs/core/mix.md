# 試聴用のミックス (core/audio)

- 対象: `stereoOf` / `resampled` / `mixAt`
- テストコード: `tests/unit/core/MixTest.cpp`
- 根拠: docs/SPEC.md §7（変換の前後に試聴できる）

## 何を保証するか

スライスをステレオにそろえ、指定した時刻に重ねて、曲全体の試聴用の音を作れること。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| MIX-001 | モノラル S16 の 0x4000 | ステレオにする | 左右とも 0.5 |
| MIX-002 | 3 ch の PCM | ステレオにする | 1・2 ch 目だけが左右になる |
| MIX-003 | 1000 Hz の 0, 1, 2, 3 | 2000 Hz にする | 0, 0.5, 1, 1.5, 2, 2.5, 3（線形補間。最後の値で終わる） |
| MIX-004 | 1000 Hz の空の出力に、0.5 の音 2 フレームを 0.002 秒と 0.003 秒に重ねる | 重ねる | 長さ 5 フレーム。2 フレーム目 0.5、3 フレーム目 1.0（重なった分は足される）、4 フレーム目 0.5 |
| MIX-005 | 出力 2000 Hz、音 1000 Hz | 重ねる | 音が 2000 Hz に変換されてから重なる |
