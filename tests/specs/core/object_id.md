# オブジェクト ID (core/bms)

- 対象: `formatObjectId` / `parseObjectId` / `maxObjectId`
- テストコード: `tests/unit/core/ObjectIdTest.cpp`
- 根拠: docs/SPEC.md §3.2、§5.3

## 何を保証するか

BMS の 2 文字の ID を、36進数（`0-9A-Z`、大文字と小文字を区別しない）と 62進数（`0-9A-Za-z`、区別する）で正しく書き、読めること。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| OID-001 | 36進数 | 1・35・36・1295 を書く | `01`・`0Z`・`10`・`ZZ` |
| OID-002 | 62進数 | 36・61・62・3843 を書く | `0a`・`0z`・`10`・`zz` |
| OID-003 | | 0、36進数の 1296、62進数の 3844 を書く | 例外（`00` は「なし」の意味で、上限は 1295 / 3843 個） |
| OID-004 | 62進数 | `Aa` と `aA` を読む | 656（10×62+36）と 2242（36×62+10）。別の値になる |
| OID-005 | 36進数 | `zz` と `aA` を読む | 1295 と 370（小文字は大文字と同じ値） |
| OID-006 | | `0`・`001`・`0!` を読む | 読めない（値なし） |
| OID-007 | 36進数・62進数 | 1 から上限までのすべての値を書いて読み戻す | 元の値に戻る |
