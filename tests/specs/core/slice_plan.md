# スライスの割り出し (core/slicing)

- 対象: `planSlices`
- テストコード: `tests/unit/core/SlicePlanTest.cpp`
- 根拠: docs/SPEC.md §5.1、§5.2、§6.2.1

## 何を保証するか

bmson の各ノーツが鳴らす音声の区間（スライス）を、bmson で鳴らしたときと同じになるよう求めること。同じ区間はまとめ、パラ音と BGM 音を見分けて番号を振ること。

共通の前提: BPM 120、resolution 240（1 拍 = 0.5 秒）、音声のサンプルレート 1000 Hz、長さ 10000 フレーム（10 秒）。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| SLC-001 | 同じチャンネルに y=0（c=false）と y=480（c=true） | スライスを求める | 1 つ目は 0〜1000、2 つ目は 1000〜10000 フレーム（次のノーツまでと、続きから最後まで） |
| SLC-002 | ノーツが 1 つだけ | スライスを求める | 0〜10000 フレーム（音声ファイルの最後まで） |
| SLC-003 | y=0（c=false）、y=480（c=false） | スライスを求める | 2 つ目は 0〜10000。ただし 1 つ目と区間が違うので別のスライス（c=false は先頭からやり直す） |
| SLC-004 | 最初のノーツが y=480（c=true） | スライスを求める | 1000 フレームから始まる（曲の先頭からの経過時間） |
| SLC-005 | 同じチャンネルの y=0 に x=1 と x=2（和音） | スライスを求める | スライスは 1 つで、ノーツは 2 つともそのスライスを指す |
| SLC-006 | 同じ音声の 2 つのチャンネルで、区間がまったく同じノーツ | スライスを求める | 1 つにまとまる |
| SLC-007 | 区間は同じだが音声ファイルが違う | スライスを求める | 別のスライス |
| SLC-008 | 同じ区間を鍵盤（x=1）と BGM（x=0）の両方で使う | スライスを求める | 1 つにまとまり、パラ音として扱われる |
| SLC-009 | 同じチャンネルの同じ位置に x=1 と x=0 | スライスを求める | BGM のノーツは書き出さない（数を記録する） |
| SLC-010 | 鍵盤のノーツに `up` = true | スライスを求める | そのノーツは書き出さない（数を記録する） |
| SLC-011 | y=9600（20 秒）のノーツ（c=true） | スライスを求める | 長さ 0 のスライスになり、「音声の長さより後」の数を記録する |
| SLC-012 | y=0 に BGM、y=240 に鍵盤、y=480 に BGM（区間はすべて違う） | 番号を求める | 並びは最初に使う時刻の順。パラ音と BGM 音はそれぞれ 1 から番号が振られる（BGM 1、鍵盤 1、BGM 2） |
| SLC-013 | y=240 に 240 パルスの STOP。y=0（c=false）と y=480（c=true） | スライスを求める | 1 つ目は 0〜1500 フレーム（停止の 0.5 秒を含む） |
| SLC-014 | 鍵盤のノーツに l=480、BGM のノーツに l=480 | スライスを求める | 鍵盤のノーツは長さ 480 を保つ。BGM のノーツの長さは 0 |
