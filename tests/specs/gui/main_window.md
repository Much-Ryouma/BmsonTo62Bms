# 画面 (gui)

- 対象: `MainWindow`
- テストコード: `tests/gui/MainWindowGuiTest.cpp`（画面を出さずに実行する。音声の出力と外部プレイヤーはテスト用の偽物に差し替える）
- 根拠: docs/SPEC.md §7、§9.1、§9.2

## 何を保証するか

画面の操作で、変換・書き出し・試聴・外部プレイヤーの起動ができること。設定が exe の横の ini に残ること。

共通の前提: 一時フォルダに 16 bit の WAV 2 つと、それを使う bmson（スライス 5 個）を置く。

| GUI-001 | | bmson を開く | スライスの一覧が 5 行、要約に「スライス 5 個」、書き出し先は bmson の横の `.bme` |
| GUI-002 | bmson を開いた | パラ音の名前を `{src}_{index:02}` にする | 一覧のファイル名と、名前の例が変わる |

| GUI-004 | bmson を開いた | 書き出す | 音声ファイルと BMS ができ、「外部プレイヤーで開く」が押せ、試聴する音が「書き出したファイル」になる |
