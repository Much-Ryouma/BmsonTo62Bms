# 画面 (gui)

- 対象: `MainWindow`
- テストコード: `tests/gui/MainWindowGuiTest.cpp`（画面を出さずに実行する。音声の出力と外部プレイヤーはテスト用の偽物に差し替える）
- 根拠: docs/SPEC.md §7、§9.1、§9.2

## 何を保証するか

画面の操作で、変換・書き出し・試聴・外部プレイヤーの起動ができること。設定が exe の横の ini に残ること。

共通の前提: 一時フォルダに 16 bit の WAV 2 つと、それを使う bmson（スライス 5 個）を置く。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| GUI-001 | | bmson を開く | スライスの一覧が 5 行、要約に「スライス 5 個」、書き出し先は bmson の横の `.bme` |
| GUI-002 | bmson を開いた | パラ音の名前を `{src}_{index:02}` にする | 一覧のファイル名と、名前の例が変わる |
| GUI-003 | bmson を開いた | パラ音の名前を `{oops}` にする | 名前の例にエラーが赤で出て、「書き出す」が押せない |
| GUI-004 | bmson を開いた | 書き出す | 音声ファイルと BMS ができ、「外部プレイヤーで開く」が押せ、試聴する音が「書き出したファイル」になる |
| GUI-005 | 書き出し済み | もう一度書き出し、上書きの確認で「いいえ」 | 確認に BMS のパスが出て、書き出さない |
| GUI-006 | bmson を開き、1 行目を選んだ | スライスを再生 | 音声の出力に、そのスライスの長さの音が渡る |
| GUI-007 | bmson を開いた | 曲全体を再生 | 音声の出力に、最後のノーツの時刻より長い音が渡る |
| GUI-008 | 外部プレイヤーを設定済み | 書き出す前／書き出した後に「外部プレイヤーで開く」 | 前はエラーのメッセージ。後はプレイヤーが BMS の絶対パスで起動される |
| GUI-009 | 設定（OGG、品質 7、フェード）を変えて閉じた | 画面を開き直す | 同じ設定が ini から読み込まれる |
| GUI-010 | | 切り口・音声の形式を切り替える | フェードの長さはフェードのときだけ、OGG の品質は OGG のときだけ変えられる |
